# Caesar Cipher

A beginner-friendly Python command-line program that encrypts and decrypts messages using the Caesar cipher.

## Features

- Encrypts and decrypts uppercase and lowercase letters
- Preserves spaces, punctuation, and numbers
- Lets you choose a shift value from 0 to 25

## Requirements

- Python 3

## Run the program

```bash
python caesar_cipher.py
```

## Example

```text
=== Caesar Cipher ===
Enter your message: Hello, World!
Enter shift value (0-25): 3
Do you want to encrypt or decrypt? (e/d): e
Result: Khoor, Zruog!
```

## How it works

The Caesar cipher shifts each letter by a chosen number of places in the alphabet. For example, with a shift of 3, `A` becomes `D`.

## Note

This cipher is for learning and practice. It is not secure enough to protect private or sensitive information.
